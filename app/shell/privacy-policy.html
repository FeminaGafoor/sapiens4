Privacy Policy

Version 2026-11-18

Local data and AI services

Sapiens stores application settings, workspaces, conversations and files locally in your selected data and configuration folders. Using a third-party AI provider or remote connection can send the content and context needed for that task to the provider or paired device. Their privacy terms apply separately from usage telemetry.

Basic usage telemetry

When enabled, Sapiens sends usage event names and times, the application version, OS and runtime information, device categories, pseudonymous installation, workspace, agent and device identifiers, and relevant feature metadata such as provider/model identifiers and attachment counts. Device identifiers are derived from platform identifiers; pseudonymous identifiers are not a guarantee of anonymity.

The application's built-in usage events do not include conversation text, prompts, file contents, file paths or account credentials. The telemetry endpoint also receives network information such as an IP address, which may appear in service security logs.

Why telemetry is used

Telemetry helps improve Sapiens, understand how features are used, investigate failures and diagnose performance or reliability issues.

Your choice

Acceptance of the Terms of Service is recorded locally with the document version. It is separate from the telemetry setting and does not by itself provide consent for optional processing where separate consent is required. New installations leave telemetry off until you enable it in Settings. A previously saved telemetry choice is retained.

You can disable or re-enable telemetry in Settings. Changing this setting does not revoke your acceptance of the terms. A registered installation makes one brief attempt to report an explicit telemetry setting change, including disabling it; afterward ordinary telemetry stops. Disabling collection does not automatically delete events already received.
